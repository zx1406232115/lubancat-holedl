# 板端运行证据

> 全部证据均由 **`EmbedFire LubanCat-1`（RK3566 / aarch64）开发板实际运行产生**，
> 不是 PC 上的模拟结果。

## 关于「截图」

这块开发板**没有连接显示器**，因此无法对板端终端做屏幕截图。
这里的 `.png` 是用 `tools/render_evidence.py` 把**板端原始输出文本逐字渲染**成
终端风格图片，内容与同名 `.txt` / `.log` 完全一致，没有任何改动或美化。

- 报告里使用图片是为了排版直观；
- **需要核验时请以 `.txt` / `.log` 原文为准**，它们是板端 `tee` 出来的原始文件，
  可以用 `scp` 直接从板子取回、逐字节比对。
- 本项目不使用任何「模拟截图」，凡标注为板端证据的内容都能在板子上复现。

## 如何自行复现

在板子上（或任何 Linux 机器上）：

```bash
cd ~/linux-homework
make                       # 原生编译
bash tests/run_tests.sh    # 31 项功能自测
bash scripts/board-evidence.sh   # 重新生成 01 / 03 / 04 三个证据文件
bash scripts/board-resume-demo.sh # 重新生成 02（真实中断+续传）
```

在 PC 上把文本证据渲染成图片：

```bash
python tools/render_evidence.py
```
